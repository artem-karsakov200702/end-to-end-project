# Week 13. ML-блок: поиск аномалий температуры

## Выбранный сценарий

Выбран вариант B — аномалии. В проекте используются погодные данные Open-Meteo по Нью-Йорку, но нет готовой целевой переменной `target`, поэтому supervised-модель была бы искусственной. Для этой недели выбран простой и прозрачный сценарий поиска аномальных значений температуры.

## Данные

Источник: `data/normalized/variant_05/*.csv`  
Гранулярность: 1 строка = 1 час наблюдения  
Анализируемая метрика: `temperature_2m`

## Метод

Использован простой IQR-метод.

1. Рассчитаны квартиль 1 (`Q1`) и квартиль 3 (`Q3`) по температуре.
2. Найден межквартильный размах: `IQR = Q3 - Q1`.
3. Построены границы:
   - нижняя граница = `Q1 - 1.0 * IQR`
   - верхняя граница = `Q3 + 1.0 * IQR`
4. Точка считается аномалией, если температура выходит за эти границы.

Дополнительно для каждой строки рассчитывался `z_score` и расстояние до ближайшей IQR-границы.

## Результат

На текущем наборе данных явные аномалии по правилу IQR не обнаружены.  
Файл `docs/ml/anomalies_top.csv` был создан, но содержит только заголовки без строк, так как ни одно значение температуры не вышло за статистические границы.  
График ряда и границ метода сохранён в `docs/ml/metrics.png`.

## Интерпретация

Полученный результат означает, что в выбранном периоде температурный ряд оказался достаточно ровным относительно IQR-критерия. Это не ошибка кода и не проблема сохранения CSV, а честный результат выбранного метода: подозрительных точек по текущему правилу не найдено.

## Leakage и честность оценки

Target в признаки не добавлялся, потому что target отсутствует. Для этой недели выбран не supervised ML, а прозрачная эвристика на основе статистических границ. Такой подход не использует “подсматривание” в ответы, но в production-сценарии границы аномальности всё равно лучше оценивать на историческом train-периоде и затем применять к более поздним данным.

## Вывод

IQR-подход полезен как простой мониторинг температурного ряда: он быстро показывает, есть ли подозрительные выбросы. В текущем периоде аномалии не обнаружены, поэтому для более содержательного анализа желательно использовать более длинную историю наблюдений, более узкие пороги или дополнительные признаки.
